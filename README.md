# 🔒 Ключалката на Хогуортс

Интерактивна **ескейп стая по света на Хари Потър** — изцяло като статичен уебсайт.
Без сървър, без база данни: целият напредък се пази в `localStorage` на браузъра.

> Полунощ е. Печатът на Основателите е заключил замъка. Имаш **60 минути**, десет зали
> и девет руни, за да сглобиш Ключовото Слово и да излезеш.

---

## Как се пуска

Няма стъпка за компилиране. Достатъчен е обикновен статичен сървър
(ES модулите не работят през `file://`):

```bash
python3 -m http.server 8000
# после отвори http://localhost:8000
```

Работи и директно от GitHub Pages, Netlify, Vercel или всяка друга статична хостинг услуга.

## Съдържание на стаята

Играта започва с **Разпределителната шапка** — шест въпроса, които определят дома ти
и оцветяват целия интерфейс. След това следват десет зали, всяка отключваща следващата:

| № | Зала | Загадка | Руна |
|---|------|---------|------|
| I | Перон 9¾ | Намиране на бариерата + „три нагоре, две настрани“ по тухлената стена | О |
| II | Голямата зала | Логическа задача с призраците на четирите дома + ключалка с четири колелца | Р |
| III | Подземието на отварите | Оригиналната загадка на Снейп със седемте шишенца | А |
| IV | Забранената секция | Съпоставяне на осем заклинания + книжен шифър „ред·дума·буква“ | Х |
| V | Астрономическата кула | **3D небесна сфера** (three.js) — петте звезди на рода Блек в правилен ред | О |
| VI | Кабинетът по Защита | Дуел с богърт на време: осем заплахи, осем заклинания, три живота | М |
| VII | Стаята на тайните | Змийска пътека по плочника, изписваща „Салазар Слидерин“ + чешмата | Л |
| VIII | Трезор 713 | Гоблинска ключалка тип „Mastermind“ с пет камъка и златни/сребърни точки | О |
| IX | Нужната стая | Анаграмата на дневника: `TOM MARVOLO RIDDLE` → `I AM LORD VOLDEMORT` | А |
| X | Огледалото Еиналеж | Пренареждане на деветте руни в заклинание + въпросът на Дъмбълдор | ★ |

Деветте руни се събират в **АЛОХОМОРА** — заклинанието, което отваря последната врата.

Очаквано време за решаване: **50–60 минути**.

## Механики

* **Часовник от 60 минути**, който тече само докато играеш и се запазва между посещенията.
* **Подсказки** — по три на зала, всяка струва 2 минути от оставащото време.
* **Наказания** — груба грешка отнема 30 секунди (а някои провали — доста повече).
* **Бележник**, вграден в интерфейса, за кодове и хрумвания.
* **Оценка накрая** по скалата на СОВА: Изключителна / Над очакванията / Приемлива / Слаба / Тролска,
  плюс точки за дома според времето, грешките и подсказките.
* Можеш да се върнеш във всяка вече решена зала през лентата с напредъка.

## Как е направено

| Част | Технология |
|------|------------|
| Логика и интерфейс | чист ES-модулен JavaScript, без рамки и без билд |
| 3D | [three.js](https://threejs.org) — фонови плаващи свещи и интерактивна небесна сфера |
| Звук | WebAudio API — всички ефекти се синтезират в реално време, няма аудио файлове |
| Графика | ръчно нарисувани SVG (гербове, шишенца, дракон, огледало, шапка) |
| Анимации | CSS keyframes + `requestAnimationFrame` |
| Запис | `localStorage` (ключ `hogwarts_escape_v1`) |
| Снимки | няколко фонови текстури от Wikimedia Commons, всяка с резервен вариант |

Ако `three.js` не се зареди по някаква причина, Астрономическата кула автоматично
преминава в равнинен режим и загадката остава решима. Ако някоя снимка не се зареди,
тя просто изчезва, без да се чупи оформлението. Има и уважение към
`prefers-reduced-motion`.

## Структура

```
index.html
css/
  base.css        обвивка, HUD, типография, преходи
  rooms.css       стилове на всяка зала
js/
  game.js         оркестраторът: зали, руни, финал
  state.js        localStorage и часовникът
  ui.js           HUD, подсказки, бележник, врати между залите
  audio.js        синтезирани звуци
  fx.js           частици, искри, toast, разтърсване
  art.js          SVG гербове и предмети
  sorting.js      Разпределителната шапка
  three-bg.js     3D фон
  three-sky.js    3D небесна сфера за зала V
  config.js       външни изображения
  rooms/          r1…r10 — по един модул на зала
  lib/three.module.js
```

Добавянето на нова зала е един файл в `js/rooms/` с експортирани `meta` и `mount(root, api)`,
плюс един ред в масива `ROOMS` в `js/game.js`.
